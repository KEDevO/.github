### About KeDevO

We are a UK-based full-stack software development studio specializing in building **reliable, scalable, and production-ready** solutions.

From concept to deployment and ongoing maintenance — we deliver software that actually works in the real world. No hype, just results.

**What we build:**
- Modern web applications
- High-performance RESTful APIs
- Robust server infrastructure & DevOps
- Data automation & intelligent scraping engines

We specialize in **.NET**, **Python (Flask)**, **React**, **Docker**, and modern DevOps practices — always with a strong focus on reliability, security, and performance.

---

### Our Expertise

- **Web Applications** — Blazor, React, Flask, TypeScript
- **Backend & APIs** — .NET 8, Python, RESTful services with sub-200ms response times
- **Infrastructure** — Linux servers, Docker, CI/CD pipelines, WireGuard VPN mesh networks
- **Monitoring** — Real-time dashboards with 99.9% uptime SLA
- **Data Automation** — High-volume web scraping with proxy rotation and parallel execution

---

### Selected Projects

- **YardPro** — Comprehensive vehicle dismantling & parts inventory management platform (50,000+ parts catalogued)
- **AutoScraper Engine** — Advanced web scraping system processing 10K+ listings daily
- **Infrastructure Monitoring** — Real-time status dashboard tracking 60+ services across multiple VPS nodes
- **TopCoasters** — Modern e-commerce platform built with React & TypeScript
- **Chartexa** - High-performance, cross-platform charting and data visualisation engine. 

All projects run with enterprise-grade reliability and 99.9% uptime.
